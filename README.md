# 🌐 Aman's Portfolio

This is my personal **developer portfolio** built with **Next.js**, enhanced with **Framer Motion** for smooth animations, and optimized using **React.memo** for performance improvements.

## 🔧 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** Tailwind CSS
- **Animation:** [Framer Motion](https://www.framer.com/motion/)
- **Optimization:** React.memo for performance
- **Deployment:** [Vercel](https://vercel.com/)

## 📂 Features

- ✨ Smooth page transitions and animations using Framer Motion  
- 🧠 Optimized components with React.memo  
- 🧩 Fully responsive design for all screen sizes  
- 📄 Showcases my projects, skills, and contact info  
- 💼 Professional and modern UI
